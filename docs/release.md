# リリース手順

リリース直前に明示的な指示を受けて、対象バージョンの backlog と対象コミットの差分を確認する。backlog のタスク文をそのまま写さず、最終的なユーザー影響を `CHANGELOG.md` と `CHANGELOG.ja.md` にそれぞれ記す。

完了したタスクは版を切るまで `- [x]` として backlog に残す。バージョンを上げてタグを打つ変更では、対象バージョンの完了項目と両 CHANGELOG を同じコミットに揃え、その版の backlog グループを削除する。削除前に、今後も守る理由・制約がコード、テスト、文書、ADR のいずれかに残っていることを確かめる。
