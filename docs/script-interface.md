# 外部スクリプトとの契約

Koecho に登録するカスタムスクリプトの「コマンド」は、`/bin/sh -c` に渡すシェルコマンド文字列である。引数、パイプ、リダイレクトを書ける。空白を含むパスはシェル用に引用する（例: `'/path/to/my script.sh' arg1`）。作業ディレクトリは一時ディレクトリであり、アプリの作業ディレクトリに依存しない。

## 入出力

| 経路 | 契約 |
| --- | --- |
| 標準入力 | 入力パネルの本文全体を UTF-8 で渡す。 |
| 標準出力 | 加工後の本文を UTF-8 で受け取る。前後の空白・改行を除いた結果が入力パネルの本文を置き換える。 |
| 標準エラー出力 | 失敗の説明に使う。本文の出力先にはしない。 |
| 終了コード | `0` を成功、それ以外を失敗とする。標準出力が空白・改行だけの場合も失敗として扱う。 |

手動実行に失敗した場合、元の本文を残す。スクリプトは何度でも実行でき、成功後の本文を次の実行へ渡せる。確定時の自動実行は、置換ルールの適用と前後の空白・改行の除去が済んだ本文を受け取り、ペースト前に行われる。自動実行が失敗した場合は加工前の確定本文をパネルに残してエラーを示し、貼り付けには進まない。

## 環境変数

Koecho が渡す環境は次の変数に限る。`PATH` と `HOME` は親プロセスから継承し、`__CF_*` など macOS の内部環境変数は渡さない。

| 変数 | 値 |
| --- | --- |
| `KOECHO_SELECTION` | 手動実行時に入力パネル内で選択されている文字列。未選択なら空文字列。 |
| `KOECHO_SELECTION_START` | パネル本文先頭を 0 とした選択開始位置。UTF-16 code unit 単位。 |
| `KOECHO_SELECTION_END` | 同じ単位の選択終了位置。終端は含まない。 |
| `KOECHO_PROMPT` | 実行前の追加入力。未入力なら空文字列。 |

未選択時の開始位置と終了位置は、ともにキャレット位置になる。外部アプリから取り込んだ選択テキストはパネルの本文に入り、キャレットは末尾に置かれる。そのまま実行すると `KOECHO_SELECTION` は空文字列になるため、選択値として渡すにはパネル内で選び直す。

例えば `😀abc` の `b` を選ぶと `KOECHO_SELECTION=b`、`KOECHO_SELECTION_START=3`、`KOECHO_SELECTION_END=4` になる。`😀` は UTF-16 code unit では 2 個分なので、この位置を Python の `str` の添字としてそのまま使えない。

確定時の自動実行では、3 つの選択関連変数はすべて空文字列になる。追加入力を必要とするスクリプトは自動実行の対象にならない。

## 中断と制限時間

既定の制限時間は 30 秒。時間切れでは Koecho が直接起動した Process に SIGTERM を送り、5 秒後も実行中なら SIGKILL を送る。パネルをキャンセルした場合も、実行中の Process に中断を伝え、貼り付けと履歴記録には進まない。スクリプトが起動した任意の子孫プロセスの停止や、実行済みの外部作用の取り消しは保証しない。

最小のコマンド例は `cat`。フィラーを削除する例は `sed 's/えーと//g'`。
