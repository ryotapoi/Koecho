# Koecho の要件

## 目的

Koecho（こえこ / Ko-echo）は macOS 27.0 以降で使う軽量な音声入力アプリ。名前は「声」と「ちょっと」に由来し、echo（反響）も掛けている。オンデバイスで認識した音声とキーボード入力をフローティングパネルで扱い、必要なら置換ルールやシェルスクリプトで加工して、元のアプリへ貼り付ける。

- フォアグラウンドアプリの選択テキストを入力の出発点にできるようにし、確定まで編集・加工・キャンセルを選べるようにする。手動スクリプトの成功直後には、加工前の本文へ一時的に戻せるようにする。
- 音声認識が管理する未確定テキストと IME の変換中テキストを、置換や確定本文の同期で壊さない。音声認識とキーボード入力を同じパネルで併用できるようにする。
- 保存済みの設定や履歴を読み込めない場合、元データを通常の保存・整理操作で無断上書きしない。利用者の確認を経た初期化を可能にする。
- 音声認識した本文を OS の診断ログへ出さない。音声認識本文が診断ログに残らないようにする。

## 制約と非目標

- App Sandbox は無効にする。選択テキスト取得と貼り付けには Accessibility 権限、グローバルホットキー監視には環境によって別途 Input Monitoring 権限が必要になる。
- Mac App Store では配布しない。
- 後方互換性の維持は原則として行わない。旧シンボルのリネーム保持・re-export・deprecated コメント・旧形式へのフォールバック分岐は、互換性が明示的に要求された場合に限る。

実装全体にまたがる技術判断は [`decisions/`](../decisions/) の current な ADR、外部スクリプトとの契約は [script-interface.md](script-interface.md) を参照する。
