# 手動スクリプトの一時 Undo

手動で実行した custom または内蔵スクリプトが成功したとき、実行直前の入力パネル本文を一時的に保持する。直近の成功1回分だけが対象で、Undo を押すと本文を復元して復元先を消費する。失敗、空出力、実行前の prompt 表示では新しい復元先を作らない。

入力パネル本文の編集が始まると復元先を失効させる。キーボード・IME・置換による本文変更に加え、本文欄に未確定の音声プレビューが表示された時点でも失効する。未確定音声は画面に残り、通常どおり更新・確定される。確定した音声による本文変更も失効対象である。prompt 欄だけの編集や、選択・カーソル移動だけでは失効しない。確定操作を受理した時点、パネルのキャンセル、次回表示でも失効する。

ここでいう auto-run は、確定時に選択済みのスクリプトを実行する機能であり、一時 Undo の対象外とする。置換ルールは別の機能で、本文を変更した場合は他の編集と同様に Undo を失効させる。履歴は従来どおり、貼り付けに成功した最終本文だけを記録する。
