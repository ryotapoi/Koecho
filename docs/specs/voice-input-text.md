# 音声入力テキストの確定と重複除去

## 目的

音声入力で確定したテキストを入力パネルへ反映する際の契約を定める。主要機能としての位置付けは[スコープ](../rules/scope.md#音声入力エンジン)を正とし、この文書は確定テキストの扱いと、重複が生じた場合の除去規則を定める。

SpeechAnalyzer は連続した音声ストリームを扱うため、キーボード入力やカーソル移動が音声の区切りに割り込むと、次の確定テキストに直前のテキストが再び含まれることがある。この重複がユーザーに見えないようにするのがここで定める振る舞いである。方針の経緯は [ADR 0016](../decisions/0016-accumulated-text-overlap-removal-for-speechanalyzer.md) を参照する。

## 割り込み時の扱い

- ユーザーがキーボード入力・カーソル移動で音声入力に割り込んだ場合、音声認識のセグメントバッファを破棄し、以降の確定テキストは新しいバッファから始める。この間もマイク入力は止めない（録音は継続し、ユーザーから見て音声入力は途切れない）。
- 割り込みが起きなかった場合、この破棄は行わない。

## 重複除去

セグメントバッファの破棄が効かなかった場合に備え、確定テキストの重複を検出して除去する。

- 音声入力で確定したテキストを蓄積し、その末尾と新しい確定テキストの先頭が一致する場合、一致部分を新しいテキストから取り除く。
- **一致が 1 文字の場合は、その文字が句読点のときだけ除去する。** 「おはよう」の直後に「うん」と発話したときの「う」のような偶然の一致で、正しいテキストを削らないため。
- **一致が 2 文字以上の場合は常に除去する。**
- 一致がない場合は新しいテキストをそのまま使う（通常の音声入力に影響しない）。

蓄積したテキストは、入力パネルを開いたとき・エンジンを切り替えたとき・状態をリセットしたときにクリアする。

## 適用範囲

- 蓄積の対象は音声入力で確定したテキストのみとし、置換ルールによる変換結果やユーザーのキーボード編集は反映しない。音声由来の重複とユーザーの意図した編集を区別するため。
- 追加入力（プロンプト）欄への確定テキストは蓄積に含めない。このため、プロンプト欄から入力欄へ戻った直後の 1 回目は重複を検出しきれないことがある（既知の限界）。
