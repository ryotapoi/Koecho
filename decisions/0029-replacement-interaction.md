# 置換ルールを確定入力に適用し、未確定入力には候補を示す

## 判断

自動置換が有効なときは、テキスト変更後に marked text や volatile text を壊さずに処理できる状態なら置換を直ちに適用する。marked text 中は本文を変更せず下線で一致を示し、volatile text 中は候補を消す。自動置換が無効なときは、確定した本文の一致候補を表示し、利用者が選んだ一箇所だけをコンテキストメニューから置換できる。

明示的な全文 Replace 操作と確定時の処理は、現在の自動置換設定にかかわらずルールを適用する。候補表示と個別操作にはテキストビュー内の描画とメニューを使い、以前の hover tooltip と別ウィンドウは使わない。

## 理由

macOS の入力メソッドが保持する marked text をプログラムで書き換えると入力を壊し得る。一方、確定後の即時適用なら貼り付け前に結果を見られる。候補を選んで一箇所だけ直したい場合は、全文に同じルールを適用する操作と分ける必要がある。表示中の本文・ルール・未確定状態が変わり得るため、個別操作は実行時に候補を再確認する。

## 採らなかった案

- 手動・確定時のみ適用する: パネル上で置換結果が見えない。
- debounce を置く: marked text を避ける条件があり、確定後の表示だけを遅らせる。
- marked text や volatile text を直接書き換える: 入力メソッドまたは音声結果と競合する。
- hover tooltip 用の別ウィンドウを持つ: 現在の候補操作はエディタ上の描画とコンテキストメニューで完結する。
