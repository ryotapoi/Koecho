# Backlog

## 運用ルール

- Backlog には、今後着手でき、完了を判定できる作業を `- [ ]` 形式のタスクとして置く。
- 完了したタスクは `- [x]` にし、版を切る変更（バージョンを上げてタグを打つ変更）で消す。取りやめたタスクは消す。
- 対応要否を決める調査もタスクにできる。観察事実だけを残さず、判断したい問いと、判断をもって完了とすることを明示する。
- 粗いメモで起票してよいが、着手前に目的と受け入れ条件を読める粒度へ詰める。
- タスクの行には短い作業名を書き、説明は空行を挟んだ字下げ段落に分ける。
- バージョン番号を付ける場合は SemVer に従う。
- タスクは `###` 見出しでグループに分ける。バージョンが確定したグループだけ、`### v0.1.0 名前` のように見出しへ番号を付ける。
- グループが大きい場合は、`####` 見出しでさらに分割してよい。

## タスク

### v2.1.0

- [x] 認識言語を巡回するショートカットを追加する

  Settings で「次の言語に切り替え」のキーを設定可能にし、入力パネル内で利用可能な言語を既存の言語選択メニューと同じ順序で巡回する。最後の言語の次は先頭に戻る。ショートカット設定と切り替え機能を1つのコミットにまとめる。

  音声OFFでも言語を切り替えられ、言語変更だけでは音声入力を開始しない。音声ONでの変更は認識言語へ反映する。設定の保存・再読み込み、言語の巡回、選択言語と認識に使う言語の一致を確認する。

- [x] 音声ボタンに現在の言語表示と選択メニューを追加する

  ショートカットのタスクに続く別コミットとして実装し、言語切り替え処理を共用する。

  利用可能な言語が2つ以上の場合、音声ボタンのラベルを現在の言語コード（`ja`、`en-US` など）に置き換え、右に下向きシェブロンを表示する。言語表示には `en-US` など5文字が収まる程度の固定幅を確保し、言語を切り替えてもボタンの幅が変わらないようにする。対応する言語コードが5文字に収まるかを実装時に確認し、超える場合の短縮表記は言語を区別できる形で決める。

  ボタン本体は音声入力のON/OFF操作と状態表示を維持し、シェブロンから言語選択メニューを開く。メニューは言語名を表示し、現在の選択にチェックを付ける。利用可能な言語が1つの場合は従来の音声ボタンを維持し、表示切り替え専用の設定は追加しない。

  音声OFFでも言語の表示・選択を可能にし、言語変更だけでは音声入力を開始しない。ショートカットとメニューのどちらから変更しても、選択言語・ボタン表示・認識に使う言語が一致すること、言語切り替え時にボタンの幅が変わらないこと、音声ON/OFFとメニュー選択をそれぞれ操作できることを確認する。
