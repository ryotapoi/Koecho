# Backlog

## 運用ルール

- Backlog には、今後着手でき、完了を判定できる作業を `- [ ]` 形式のタスクとして置く。
- 完了したタスクは `- [x]` にし、版を切る変更（バージョンを上げてタグを打つ変更）で消す。取りやめたタスクは消す。
- 対応要否を決める調査もタスクにできる。観察事実だけを残さず、判断したい問いと、判断をもって完了とすることを明示する。
- 粗いメモで起票してよいが、着手前に目的と受け入れ条件を読める粒度へ詰める。
- タスクの行には短い作業名を書き、説明は空行を挟んだ字下げ段落に分ける。
- バージョン番号を付ける場合は SemVer に従う。
- タスクは `###` 見出しでグループに分ける。バージョンが確定したグループだけ、`### v0.1.0 名前` のように見出しへ番号を付ける。
- グループが大きい場合は、`####` 見出しでさらに分割してよい。

- [x] 音声入力切り替えショートカットの初期値を Control + V にする

  設定が未保存の場合の初期値を Control + V にする。保存済みのショートカット設定（明示的な未割り当てを含む）は維持する。

- [ ] タイムアウト設定を一般からスクリプトタブへ移す

  スクリプト一覧下部の追加・削除ボタンと同じ行の右端に歯車アイコンを置き、クリックで開く吹き出しに「タイムアウト ［数値］ 秒」を表示する。スクリプト未選択時も操作できるようにする。全スクリプトに共通する設定であることは配置で伝え、「共通設定」などの見出しや説明は追加しない。

- [ ] 自動置換設定を一般から置換タブへ移す

  置換ルール一覧下部の追加・削除ボタンと同じ行の右端に歯車アイコンを置き、クリックで開く吹き出しに「自動置換」のオン・オフを表示する。ルール未選択時も操作できるようにする。「共通設定」などの見出しや説明は追加しない。初期値はオフを維持し、必要なタイミングでショートカットによる置換を使う形を基本とする。

- [ ] アプリアイコン切り替え機能を削除する

  現行の切り替えは Dock アイコンへの反映のみで、Dock に表示されない Koecho では普段見えるアイコンが変わらないため削除する。一般タブの選択 UI、専用の設定・保存処理・アイコン適用処理と、この機能だけで使う画像・翻訳・テストを削除する。

- [ ] 履歴設定を履歴タブへ移し、一覧周辺の配置を整理する

  一般タブの「履歴を有効にする」「最大件数」「保持日数」を、現在の3項目のグループ表示を保って履歴タブの最上部へ移す。その下に検索入力欄、履歴一覧、最下部に「全て消去」と総件数の下バーを配置する。

  検索は履歴一覧の直上に埋め込むコンパクトな入力欄とし、設定・検索欄・下バーは固定して履歴一覧だけをスクロールさせる。左右の余白を揃え、領域間は設定のグルーピングと余白で区別する。領域を分ける区切り線は追加しない。
