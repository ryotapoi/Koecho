# Backlog

## 運用ルール

- Backlog には、今後着手でき、完了を判定できる作業を `- [ ]` 形式のタスクとして置く。
- 完了したタスクは `- [x]` にし、版を切る変更（バージョンを上げてタグを打つ変更）で消す。取りやめたタスクは消す。
- 対応要否を決める調査もタスクにできる。観察事実だけを残さず、判断したい問いと、判断をもって完了とすることを明示する。
- 粗いメモで起票してよいが、着手前に目的と受け入れ条件を読める粒度へ詰める。
- タスクの行には短い作業名を書き、説明は空行を挟んだ字下げ段落に分ける。
- バージョン番号を付ける場合は SemVer に従う。
- タスクは `###` 見出しでグループに分ける。バージョンが確定したグループだけ、`### v0.1.0 名前` のように見出しへ番号を付ける。
- グループが大きい場合は、`####` 見出しでさらに分割してよい。

- [x] D2 マイクのフォールバック注意を既存の入力パネルと同じ形で表示する

  完了条件: フォールバック結果から注意表示への変換を unit test で確認し、実際のデバイス切断とシステムデフォルトへのフォールバック、注意の表示、録音・編集の継続を手動確認する。

  確認（2026-10-18）: 専用検証版で本人が上記手動確認の案内に「これは大丈夫」と受入報告。画像で注意表示と入力本文を確認し、所有 PID のログでも選択 UID 不在から default への fallback と認識開始成功を確認した。マイクの表示名・手入力継続などの項目別結果・権限再許可有無は未記録で、本人の包括報告を受入根拠とする。

- [x] 保存済み置換ショートカットの回帰テストから JSON の順序依存を除く

  発生条件・影響: `ReplacementSettingsTests.savedControlShortcutsAreNotMigrated` が、同じショートカットでも JSON のキー順・modifier の配列順の違いで失敗し、Package gate を失敗させる。D2 の検証時に変更前 HEAD でも再現した。

  作業・完了条件: 保存済みショートカットを変更しない契約を確認し、JSON の表現順に依存せずその契約の違反を検出できる検証にする。Package gate を反復実行し、ショートカットの意味の保持と順序依存の解消を確認する。

  確認（2026-10-18）: 保存先の値を ShortcutKey にデコードして意味を比較し、キー順・modifier 配列順が異なる入力を検証した。Package gate は別プロセスで3回成功（各346件、両 test target、失敗・skip・timeout・残留なし）。

- [x] 日本語入力の再変換と競合しない置換ショートカットへ既定値を変更する

  背景・対応判断: 全体置換の既定値 Ctrl+Shift+R は、Apple 標準日本語入力の「再変換」と重なる。日本語入力時だけ反応しない現象の実イベント経路は未観測だが、競合を避けるため、局所置換を Cmd+R、全体置換を Cmd+Shift+R へ変更する。音声入力の切り替えは Ctrl+V を維持する。

  作業・完了条件: 置換ショートカットの既定値と直接関係するテスト・案内を更新し、保存済みの個別設定と無効化設定を維持する。日本語入力のまま変換確定後に Cmd+R が局所置換、Cmd+Shift+R が全体置換として動作することを実 IME で確認する。未確定の変換文字列・音声テキストがある間の置換抑止、標準のコピー＆ペースト、音声切り替え Ctrl+V は維持する。連続入力による全体置換や IME 操作を奪うイベント処理は追加しない。

  確認: 専用検証版の日本語入力で局所 Cmd+R・全体 Cmd+Shift+R を試す案内後、本人から「動いたよ」と受入確認。保存済み設定の維持と編集保護は自動テストで確認。入力ソース名、変換中・コピー＆ペースト・音声切替の項目別実操作結果、権限の再許可有無は未記録。
