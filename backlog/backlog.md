# Backlog

## 運用ルール

- Backlog には、今後着手でき、完了を判定できる作業を `- [ ]` 形式のタスクとして置く。
- 完了したタスクは `- [x]` にし、版を切る変更（バージョンを上げてタグを打つ変更）で消す。取りやめたタスクは消す。
- 対応要否を決める調査もタスクにできる。観察事実だけを残さず、判断したい問いと、判断をもって完了とすることを明示する。
- 粗いメモで起票してよいが、着手前に目的と受け入れ条件を読める粒度へ詰める。
- タスクの行には短い作業名を書き、説明は空行を挟んだ字下げ段落に分ける。
- バージョン番号を付ける場合は SemVer に従う。
- タスクは `###` 見出しでグループに分ける。バージョンが確定したグループだけ、`### v0.1.0 名前` のように見出しへ番号を付ける。
- グループが大きい場合は、`####` 見出しでさらに分割してよい。

- [x] Input Panel を閉じる直前の内容をコピーできるようにする

  目的: Esc または赤いウィンドウの閉じるボタンで誤って Input Panel を閉じた場合に、閉じる直前まで入力していた内容を取り戻せるようにする。

  作業・完了条件: 履歴とは独立したメモリ上の1件領域に、確定した最終本文とEsc・赤い閉じるボタンで終了した表示本文を保持し、常設の「最後の内容をコピー」から取得できるようにする。キャンセル本文は履歴へ記録しない。空・空白のみの本文では更新せず、次の有効な本文かアプリ終了まで保持する。コピー操作は1項目に統合し、一時本文がなければ最新履歴を使用する。

- [x] 言語管理ボタンの表示と配置を整える

  目的: Settings の一般ページで、言語選択と関連する管理操作を右側にまとめ、操作を見分けやすくする。

  作業・完了条件: 「言語を管理…」を左寄せの青いリンク表示から通常のボタン表示に変更し、言語選択の次の行へ右寄せで配置する。macOS 標準のシステム設定で、ストレージ情報の次の行の右側に「ストレージ設定…」ボタンがある配置を参考にする。言語選択と管理ボタンを同じ行に密集させず、マイク設定との区切りを保つ。言語選択と管理画面を開く既存の動作を維持し、配置と操作を実画面で確認する。

- [x] 入力音量・入力レベル・ターゲット音量の配置を揃える

  目的: Settings の一般ページで、音量スライダーと入力レベルの長さ・配置のばらつきをなくす。

  作業・完了条件: マイク選択の下にある入力音量の行は、左側をマイクアイコンから「入力音量」ラベルに変更し、スライダー両端のマイクアイコンを削除する。macOS 標準の最小・最大音量アイコンは再現せず、アイコンなしのスライダーにする。入力レベルは現在の連続したバーの見た目を維持する。

  配置: 「入力音量」「入力レベル」「ターゲット音量」を左側のラベル列に置き、右側の操作・表示領域の開始位置と右端を揃える。入力音量のスライダーと入力レベルのバーは同じ長さにする。ターゲット音量は同じ領域内の右端にパーセント表示を置き、その分だけスライダーを短くする。各値の設定・反映と入力レベル表示の動作を維持し、ウィンドウ幅を変えても配置が揃うことを実画面で確認する。

- [x] 音声入力・マイク設定・音量ダッキングを3グループに分ける

  目的: 認識方法、声の入り方、システムの再生音という操作対象の違いを見出しで示し、設定を探しやすくする。

  作業・完了条件: Settings の一般ページ内で、現在の順序を保ちながら「音声入力」「マイク設定」「音量ダッキング」の3グループに分ける。「音声入力」には音声入力の有効化・言語選択・言語管理、「マイク設定」にはマイク選択・入力音量・入力レベル、「音量ダッキング」にはダッキングの有効化・ターゲット音量・説明文を置く。別の設定ページは追加しない。

  既存の設定値・動作・音声入力のオン／オフに応じた操作可否を維持し、グループ分けに伴ってダッキングの開始・復元条件を変更しない。言語管理ボタンの配置変更と各バーの配置合わせも、上記の関連タスクどおり反映する。実画面で各項目の所属と操作、ウィンドウ幅を変えた際の配置、および見出し・余白の追加による高さとスクロール量を確認する。

- [x] 履歴の年月日時刻を右揃えにする

  作業・完了条件: Settings の履歴で、年月日時刻を右揃えで常時表示し、コピー中は同じ行の左側に既存のコピーfeedbackを表示する。コピーfeedbackが消えた後も日時の位置と行高さを変えない。履歴本文の左揃えと最大2行の表示、年月日時刻の書式・フォントサイズ・色、コピーfeedbackの文字と色、および日英表記を維持する。コピー動作・タイマー・アニメーションは変更しない。

- [x] 履歴下部のボタンと件数を一覧の左右端に揃える

  作業・完了条件: Settings の履歴で、一覧の区切り線を基準に「すべて消去」ボタンの左端と合計件数表示の右端を揃える。ウィンドウ幅を変えても揃うようにし、消去操作と件数表示の動作は維持する。

- [x] 自動置換の既定値をオフにする

  目的: 「置換／痴漢」のように文脈で正解が変わる語を一律に変換せず、改善した手動置換を既定の使い方にする。

  作業・完了条件: 自動置換の初期値・設定未保存時・不正値読み込み時の既定値をオフに揃える。保存済みの有効なオン／オフは維持し、必要な利用者は引き続き自動置換をオンにできるようにする。既定値、保存後の再読み込み、未設定・不正値の扱いをテストで確認する。

- [x] 入力パネル内に「置換（全体）」ショートカットを追加する

  作業・完了条件: Settings の「ショートカット」ページの「入力パネル内のショートカット」に、既存の「置換」に加えて「置換（全体）」を追加する。既定のキーは「置換」が Control+R、「置換（全体）」が Control+Shift+R とする。既存の「置換」の設定と動作を維持し、新しいショートカットは設定・保存できるようにする。

  動作: 「置換（全体）」は現在の選択範囲にかかわらず入力パネルの本文全体へ置換を適用する。全選択して既存の「置換」を実行するのと実質同じ結果にする。入力パネル内での発火、部分選択がある場合も本文全体が対象になること、および既存の「置換」と両ショートカットの設定保存を確認する。

- [ ] 通常の置換の表記を「置換前」に揃える

  作業・完了条件: 通常の文字列置換で、置換対象を示す英語表記を「Text to replace」、日本語表記を「置換前」に変更する。編集画面の「Patterns」見出し・各入力欄と、別の追加画面も揃える。通常の文字列を追加するボタンは「Add text／置換前の文字列を追加」とする。正規表現モードでは「Pattern／パターン」を維持し、置換先は既存の「Replacement／置換後」を維持する。置換の動作と保存形式は変更せず、英語・日本語の表示と通常／正規表現モードの切替時の表記を確認する。

- [ ] ショートカット設定の見出しと項目名を簡潔にする

  作業・完了条件: Settings の「ショートカット」ページで、グループ見出し「入力パネル内のショートカット」を「入力パネル」に変更し、上の「ホットキー」見出しは維持する。各ショートカット項目名の末尾にある「ショートカット」を削除し、「音声入力切り替え」など操作名だけにする。追加予定の「置換（全体）」にも同じ方針を適用する。英語表記も同じ方針で揃え、キー設定・保存・発火の動作は維持する。

- [ ] 置換方式の切替を詳細パネルの先頭に移す

  作業・完了条件: Settings の置換の詳細パネルで、既存の「正規表現を使用」スイッチを、先頭の「置換方式」ドロップダウンに変更する。選択肢は「通常」「正規表現」とし、方式ごとの入力欄・設定・説明はその下に配置する。方式を切り替えても切替行の位置は固定し、タブやセグメンテッドコントロールは使わない。

  通常／正規表現で必要な項目の切替と、既存の設定値・保存形式・置換動作を維持する。「置換前」への表記変更も関連タスクどおり反映する。両方式の表示・切替・設定保存を実画面で確認する。

- [ ] スクリプトの種類・表示名・アイコンを先頭の1行にまとめる

  作業・完了条件: Settings のスクリプト詳細で、既存の Type 行・表示名行・アイコン行を先頭の1行にまとめる。左側には種類に応じて「Built-in」または「Custom」を表示し、右側にはアイコン選択ボタン、その右に表示名入力欄を配置する。表示名入力欄はショートカットキーの入力欄のように背景色を分け、編集できることを明示する。

  配置: 右側の編集領域の左端を固定し、タイトルの長さによってアイコン位置を動かさない。長い表示名は入力欄内で横スクロールして編集でき、行全体を押し広げない。アイコン選択ボタンは現在の大きなボタンから、スクリプトコマンドの「選択…」ボタンと同程度の高さへ縮める。独立した縦長のアイコン行は削除する。

  Built-in では次の行に既存の Feature を置き、Custom では次の行にスクリプトコマンドと「選択…」ボタンを置く。他の設定項目と、種類の固定・表示名／アイコンの設定保存・選択操作・一覧と入力パネルへの反映を維持する。両種類、長い表示名、表示名のみ・アイコンのみ・両方の設定、およびウィンドウ幅を変えた際の配置を実画面で確認する。
